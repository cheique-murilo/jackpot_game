🎰 Jackpot @bolao.animal

Este é um jogo simples que desenvolvi para o nosso grupo de bolão. O jogo foi criado em duas partes: frontend e backend.

Para o frontend em HTML, usei muita ajuda de IA (como ChatGPT e Grok) 🤪. Para o backend, usei basicamente Python.

Depois, deployei no GitHub e no Render para hospedar o jogo online. Qualquer um com o link pode jogar ▶.

Basicamente, a pessoa acessa o link, adiciona o e-mail (usamos só para mandar uma mensagem com a data e hora do vencedor) e clica em jogar 🎮. Os números são sorteados aleatoriamente entre 1 e 5 (probabilidade de 1 em 125 de ganhar 🏆). Se os 3 números forem iguais, o jogador ganha o jackpot e uma aposta especial para alguma loteria 🎁.
